JWW読み込み・変換・診断用CLI

Jw_cadの .jww ファイルを読み込み、JWW Gateway JSONと診断レポートを出力します。常駐サーバーや画面アプリへ直接接続するのではなく、生成したファイルを連携先のツールへ受け渡して使います。

JWW保存/書き出しには未対応です。元のJWWファイルは変更しません。

取扱説明を見る GitHubで開く

使い方の流れ

  1. JWW_Gateway フォルダをPowerShellで開く
  2. npm run status で配布物が揃っているか確認する
  3. npm run convert でJWWをJSONへ変換する
  4. 必要に応じて npm run diagnose で診断レポートを作る
  5. 連携先のツールで、生成されたJSONや診断レポートを読み込む

基本コマンド

npm run status
npm run convert -- "C:\path\to\file.jww" -o output.json
npm run diagnose -- "C:\path\to\file.jww" --html -o diagnostics.html
npm run validate -- output.json

できること

JWW読み込み

Jw_cad .jww ファイルを読み込み、用紙、縮尺、レイヤ、色、線種、文字情報を抽出します。

JSON変換

連携先のツールが読み込めるように、JWW Gateway JSONとして変換結果を出力します。

診断レポート

読み込みログ、未対応クラス、色テーブル、弧/楕円診断、外れ要素候補などを確認できます。

既知の制限

JWW保存/書き出しには対応していません。Jw_cad完全互換ビューアでもありません。詳しい制限と未対応項目は 取扱説明の既知の制限 を参照してください。
