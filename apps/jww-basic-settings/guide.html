User guide

Open, understand, and safely save JWW settings

JWW Basic Settings reads a Jw_cad file on your device, shows the native settings that Gateway can prove, and lets you save supported changes to a new file.

Quick start

  1. 1
    Open the app.

    Go to JWW Basic Settings.

  2. 2
    Choose a JWW file.

    Select Open JWW, then choose a local .jww file. The file stays on your device.

  3. 3
    Check the document status.

    Confirm that Parse says Clean. Review the settings and the Diagnostics section before editing an unfamiliar file.

  4. 4
    Edit supported settings.

    Only controls marked Native editable can be changed. Read-only values remain visible for reference.

  5. 5
    Save a separate copy.

    When the changes pass preflight, select Save As JWW and use a new file name. Open the result in Jw_cad to confirm the drawing.

Orientation

Reading the screen

Version

The internal JWW version reported by the parser.

Size

The byte size of the original file selected from your device.

Parse

Clean means the parser reported no unsupported, skipped, or trailing records. It is not a claim of complete Jw_cad compatibility.

Save

Unchanged means no editable field has been modified. The Save As button becomes available only after a valid supported change.

Status labels

Stored in JWW
The value came directly from the opened JWW document.
Derived
The value was calculated from native document data and is not a separate stored field.
Not stored in JWW
The setting belongs elsewhere, such as a JWF environment profile.
Unsupported / unconfirmed
Gateway does not have enough evidence to edit the value safely.
Native editable
The field has a verified native representation and may be changed.

Important value

Understanding scale

JWW stores one scale denominator for each layer group. Basic Settings shows that native numeric value without changing it into a different document model.

100means a drawing scale of 1/100
1means 1/1
1.5means 1/1.5, which is mathematically equal to 2/3

Note: JWW stores the numeric denominator, not the way a fraction was originally written. Changing a group scale changes the stored group setting; the app does not normalize every drawing entity to one scale.

Diagnostics

Understanding images

Open Diagnostics and look under Native record counts. Two separate values describe image use:

Image entities

The number of IMAGE references found in the drawing and inside block definitions.

Embedded images

The number of image payloads physically stored inside the JWW file.

For example, Image entities: 1 and Embedded images: 0 means the drawing refers to an image, but the image bytes are not contained in the JWW file. The external BMP file may still be required when the drawing is opened on another computer.

Making changes

Editing and Reset Changes

  • Use only controls marked Native editable.
  • A change is kept in the browser until you save or reset it.
  • Select Reset Changes to discard all unsaved edits and return to the values read from the opened file.
  • Read-only and unconfirmed fields cannot be forced into the JWW file.

Output

Saving safely

  1. Review the fields you changed.
  2. Check that the save status is ready and no validation message is shown.
  3. Select Save As JWW.
  4. Choose a new name. Do not replace the source file during verification.
  5. Open the saved file in Jw_cad and confirm paper, scale, layers, colors, line types, text, dimensions, blocks, and images that matter to your drawing.

Gateway runs a native save preflight before starting the browser download. If it cannot preserve the document safely, it blocks the save instead of silently dropping unsupported data.

When something looks wrong

Using Diagnostics

  • Clean parse: Yes means no parser loss was reported.
  • Unsupported records and Skipped records should normally be zero before editing.
  • Record source spans available: Yes means Gateway knows the byte boundaries needed for supported native operations.
  • Trailing unparsed bytes reports data after the parsed document boundary.
  • Preserved unknown regions lists unknown bytes that Gateway retains rather than discarding.

If parsing is not clean or Save As is blocked, keep the source file unchanged and use the diagnostic details when reporting the problem.

Scope

What this app does not do

  • It is not a complete Jw_cad-compatible drawing editor or viewer.
  • It does not edit drawing geometry such as lines, arcs, dimensions, blocks, or image placement.
  • It does not require, detect, or automatically apply a JWF file.
  • It does not invent values for fields whose binary meaning has not been proven.
  • A clean parser result does not replace a real Jw_cad reload check for an important output file.

Ready to inspect a file?

Keep the original JWW as your reference, save changes under a new name, and verify important outputs in Jw_cad.
