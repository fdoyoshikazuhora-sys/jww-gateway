Inspect and edit native JWW settings safely

Basic Settings opens Jw_cad .jww files locally and displays paper, scale, layer, color, line type, text, dimension, grid, and print settings stored in the document. Only proven native settings are editable, and results are saved as a separate JWW file. CLI conversion and diagnostic reporting remain available.

Files are processed in your browser and are not uploaded. Save As never overwrites the source JWW file.

Basic Settings workflow

  1. Open JWW Basic Settings.
  2. Select a local JWW file with Open JWW.
  3. Review stored settings, native record counts, IMAGE references, embedded image payloads, and parser diagnostics.
  4. Edit only fields marked Native editable.
  5. Use Save As JWW to download a separately named file.

CLI commands

npm run status
npm run convert -- "C:\path\to\file.jww" -o output.json
npm run diagnose -- "C:\path\to\file.jww" --html -o diagnostics.html
npm run validate -- output.json

Capabilities

Basic Settings

Display proven settings stored in JWW through an English interface and edit supported fields without replacing the native document model.

Native-safe Save As

Run preflight before saving, preserve the source file, and download the result as a separately named JWW file.

CLI conversion and diagnostics

Convert to JWW Gateway JSON and run parser diagnostics, semantic diff, and related command-line workflows.

Known limitations

Basic Settings is not a fully compatible Jw_cad drawing editor or viewer. It edits only proven JWW native metadata fields. JWF-only settings are not inferred from JWW files or applied automatically. See the release notes for detailed scope and limitations.
